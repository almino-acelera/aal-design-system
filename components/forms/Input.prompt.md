Single-line field for application forms, login and checkout.

```jsx
<Input label="Seu melhor e-mail" type="email" placeholder="nome@empresa.com" hint="Enviamos o acesso na hora." />
<Input label="Faturamento atual" error="Preencha para continuar" />
```

Labels are uppercase micro Montserrat; placeholders show the format, never repeat the label. Focus paints a gold ring. Pass `onDark` when the form sits on an olive section.
