Container for grouped content. Squared 4px corners, hairline border, shadow barely there — the brand reads editorial, not "app card".

```jsx
<Card variant="gold" padding="var(--space-8)">
  <h3>Pilar A — Análise da Lacuna</h3>
  <p>Realidade atual, estado desejado e o gap com impacto.</p>
</Card>
```

Variants `default | gold | raised | flat | inverse`. Use `interactive` only when the whole card is a link. Never add a colored left border.
